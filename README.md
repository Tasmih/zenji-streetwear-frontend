# ZENJI Tokyo Atelier

## Project Overview
ZENJI Tokyo Atelier is an ultra-premium Japanese-inspired streetwear ecommerce frontend designed with a dark, high-fashion aesthetic. It merges post-industrial technical apparel specifications (500 GSM bespoke French Terry, Cordura® ripstop, modular Fidlock® hardware) with fluid, modern web performance.

## Features
- **Premium streetwear landing page:** Interactive cinematic hero with 3D cursor parallax, Tokyo GPS coordinates, live countdown drop ticker, and animated lookbook piece switcher.
- **Product showcase:** Multi-discipline catalog with real-time category filtering (Hoodies, Graphic Tees, Utility Cargos, Modular Outerwear), keyword search, and price filtering.
- **Product detail pages:** High-resolution perspective gallery with thumbnail switcher, GSM technical fabric specifications, size/color selectors, and related piece recommendations.
- **Category filtering:** Seamless real-time filter by category, price, and search query.
- **Cart drawer UI:** Slide-over shopping bag with persistent localStorage, quantity adjusters, automated item removal, and free shipping progress bar.
- **Dark/light mode:** Dual luxury palettes with smooth CSS transitions and persistent theme memory.
- **Framer Motion animations:** Spring-physics page transitions, interactive 3D model physics, and micro-interactions.
- **Responsive design:** Pixel-perfect fluid layout optimized across mobile, tablet, laptop, and ultra-wide desktop viewports.
